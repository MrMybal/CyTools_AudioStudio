Edit multitrack audio, apply effects and supported plugins, and render sessions. Dedicated workspaces also generate sound effects, music and voices through the installed backends.

## Main workflow {#workflow}

1. Open the editor and import audio, or choose a sound, music or voice generation workspace.
2. Set the processing or generation parameters. Install only the backend and model needed for the chosen operation.
3. Preview the result, then render or export it. Keep effect tails when rendering a session, and use saved workflows or voice presets for repeatable work.

## Requirements and installation {#requirements}

Procedural audio and installed engines have different requirements. Neural generation runs in backend-specific environments. Plugin support depends on the format and the installed host components; VST2 and ASIO are not provided.

Read [Installation and models](doc:installation) for setup, the [User guide](doc:guide-lisez-moi) for detailed controls, and [Automation and API](doc:operations) for the public operation contracts.
