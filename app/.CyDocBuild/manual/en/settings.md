## Appearance {#appearance}

Open Options to select English or French, a theme and text size. Application licence information is available there. User prompts, file names and model identifiers retain their original spelling.

## Save and load {#configurations}

Use the configuration save/load controls in Options to retain the current operation settings as JSON. Loading a configuration fills the form; it does not start processing. Check the selected operation, source paths, model and device before running it. Enable generation autosave when you want a record of submitted settings. Model weights and credentials do not belong in a configuration file.

## Contextual help {#help}

Press F1 for the active workspace or open the manual from Options. Use the header search or Ctrl+K to find a task. The language selector changes the documentation language without changing technical identifiers.
